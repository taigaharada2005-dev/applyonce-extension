# ApplyOnce — 就活・転職エントリーフォーム一括入力アシスタント

就職活動や転職エントリーにおける入力フォームの反復入力作業を大幅に効率化する Chrome 拡張機能（Manifest V3 対応）です。

氏名・学歴・連絡先などの基本情報の一括入力はもちろん、**DOM構造解析**と**最新AI（OpenAI `gpt-6-luna` / Google Gemini）**を組み合わせることで、企業独自の設問やドロップダウン形式にも柔軟に適応します。

---

## 🔒 セキュリティとプライバシー（安全設計）

- **完全ローカル完結**: 登録した氏名や連絡先、学歴、APIキーは、**すべてお使いのPC上のブラウザ内（`chrome.storage.local`）にのみ安全に保存**されます。外部サーバーへの送信や収集は一切行いません。
- **機密情報の完全ガード**: パスワード、クレジットカード番号、認証コード（OTP）、規約同意チェックボックス、機微情報などは自動入力対象から除外しています。
- **自動送信なし（安全第一）**: フォームへの「下書き代行」のみを行い、**勝手な送信ボタンのクリックは行いません**。必ずユーザー本人が内容を確認してから提出してください。

---

## ✨ 主な機能

### 1. 基本情報の一括入力（ルールベース高速処理）
- **氏名**: 漢字（フルネーム／姓・名分割）、フリガナ（カタカナ・ひらがな自動変換）、ローマ字（英語名）
- **連絡先**: メールアドレス（確認用再入力欄対応）、電話番号（ハイフン有無、3分割市外局番入力欄）
- **住所**: 郵便番号（一括／3桁・4桁分割）、都道府県、市区町村、番地、建物名
- **学歴**: 大学名、学部、専攻・学科、文理区分、学位区分、在籍/卒業状況、卒業予定年・月
- **SNS・リンク**: LinkedIn、GitHub、ポートフォリオサイト等

### 2. DOM構造解析 ＋ AIによる柔軟適応（OpenAI `gpt-6-luna` / Gemini）
- **ページの構造理解**:
  HTMLの見出し（所属セクション）、入力タイプ、ドロップダウンの選択肢一覧などを自動抽出してAIに渡します。
- **基本情報の表記揺れ補完**:
  企業ごとに異なるセレクトボックスの表記（例: 「大学（学部・学士）」や「理系（理工・情報等）」）をAIが自動判別して合致させます。
- **志望動機・自己PR・ガクチカの自動作成**:
  募集要項のテキストと自分の実体験（登録した事実）を紐付け、文字数制限（maxLengthの80〜95%程度）を満たした自然なビジネス敬語（です・ます調）で文章を作成します。

### 3. モダンフレームワーク対応
- React / Vue / Angular などのSPA（Talentio, HERP, 各種マイページ等）に対応。内部セッターとイベント（`input`, `change`, `blur`）を連動させ、入力値の消失やバリデーションエラーを防ぎます。

### 4. プロフィールの管理 & バックアップ
- 設定内容を JSON ファイルとしてエクスポート＆インポート可能（※APIキーは除外して出力される安全設計）。

## 🚀 導入手順（インストール方法）

プログラミングの知識は不要です。約1分で導入できます。

### ステップ 1: Chrome に拡張機能を読み込む
1. Google Chrome を起動します。
2. アドレスバーに `chrome://extensions` と入力して Enter を押します。
3. 画面右上にある「**デベロッパーモード**」のスイッチを **ON** にします。
4. 画面左上に現れる「**パッケージ化されていない拡張機能を読み込む**」をクリックします。
5. 本フォルダ（`applyonce-extension`）を選択して読み込みます。
6. Chrome ツールバー右上のパズルピースアイコン（拡張機能メニュー）を開き、「**ApplyOnce**」のピン留めアイコンをクリックして固定します。

### ステップ 2: 自分の情報を登録する
1. ツールバーの **ApplyOnce アイコン（青い A のマーク）** をクリックします。
2. ポップアップ右上の「**プロフィール設定 ↗**」をクリックします。
3. 各入力欄に、ご自身の情報を登録します：
   - **基本情報**: 氏名、連絡先、生年月日、住所など
   - **学歴・専攻**: 学校名、学部、学科、卒業予定など
   - **経験と文章の素材**: ガクチカ、自己PRの軸、研究内容、スキルなど（AIが文章作成時に事実として使用します）
4. **AI機能を利用する場合（推奨）**:
   - セクション04「AI連携」で、**AIプロバイダー（OpenAI 推奨）** を選択します。
   - OpenAI APIキー（`sk-...`）を入力し、**「接続テスト」** を押して正常に応答することを確認します。
   - モデルは **`gpt-6-luna`**（高速・安価・構造理解に最適）がデフォルトで選択されています。
5. 最下部の **「プロフィールを保存 →」** をクリックして保存を確定します。

## 📝 実際の応募フォームでの使い方

1. 企業の採用応募ページ（エントリーフォーム）を開きます。
2. ツールバーの **ApplyOnce アイコン** をクリックします。
3. 目的に応じてボタンを選択します：
   - **「保存した情報を一括入力」**:
     保存した基本情報（氏名・連絡先・学歴等）をルールベースで即座に入力します。
   - **「✦ 企業向けにAI調整して入力」**:
     ページの構造や募集要項を解析し、基本情報の表記揺れ補完に加えて、設問（志望動機・ガクチカ・自己PR等）の文章を自動生成して入力します。
4. **提出前の最終確認**:
   - 入力された項目を目視確認します。
   - ファイル添付（履歴書PDF等）や利用規約への同意チェックを手動で行い、送信してください。

## 🧪 動作テスト用デモページ

拡張機能が正しく動作するか確認できるテスト用フォーム（`demo-form.html`）を同梱しています。

1. `chrome://extensions` を開き、ApplyOnce の「**詳細**」をクリックします。
2. 「**ファイルのURLへのアクセスを許可**」を **ON** にします。
3. `applyonce-extension/demo-form.html` を Chrome の画面にドラッグ＆ドロップして開きます。
4. 拡張機能ポップアップから「保存した情報を一括入力」または「✦ 企業向けにAI調整して入力」を試すことができます。
