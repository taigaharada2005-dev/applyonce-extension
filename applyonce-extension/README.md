# ApplyOnce — 就活・転職エントリーフォーム一括入力アシスタント (Chrome 拡張機能)

就職活動や転職エントリーにおける入力フォームの反復入力作業を大幅に効率化する Chrome 拡張機能（Manifest V3 対応）です。

**【完全個人完結・安全設計】**
- 入力情報はすべて**あなたのPC上のブラウザ内（ローカルストレージ）にのみ安全に保存**されます。
- パスワード、クレジットカード番号、認証コード、規約同意チェックボックス等は自動入力から除外され、勝手な自動送信は一切行いません（必ず人間による目視確認を前提としています）。

---

## 主な機能

1. **基本情報の一括自動入力**:
   - 氏名（漢字フルネーム、姓・名分割、ローマ字 / 英語名）
   - フリガナ（カタカナ、ひらがな自動変換対応）
   - 連絡先（メールアドレス、確認用再入力欄、携帯電話、ハイフン有無、3分割市外局番入力欄）
   - 住所（郵便番号・分割3/4桁、都道府県、市区町村、番地、建物名）
   - 学歴（大学名、学部、学科・専攻、文理区分、学位区分、卒業見込み/卒業、卒業予定年・月）
   - 各種リンク（LinkedIn、GitHub、ポートフォリオURL）

2. **DOM構造解析とAI連携（OpenAI `gpt-6-luna` / Gemini 対応）**:
   - ページのHTML構造（所属セクション見出し、ドロップダウンの選択肢一覧など）を取り出してAIに渡します。
   - フォーム特有の表記揺れ（例: 「大学（学部・学士）」の選択肢など）をAIが柔軟にマッピング・補完。
   - 募集要項と自分の実体験に基づき、文字数制限（maxLength）を満たした自然な志望動機・自己PR・ガクチカ等の文面を自動作成。

3. **React / Vue などのモダン採用システム（Talentio, HERP, 自社フォーム等）に完全対応**:
   - DOMイベント（`input`, `change`, `blur`）を正しく発火させ、入力検証エラーを起こさず確実に値を反映します。

4. **データのバックアップ・移行**:
   - JSONエクスポート & インポート機能により、PCの移行やバックアップもワンクリックで可能です（APIキーはJSONに含まれない安全仕様）。

## 導入手順（受け取った方の設定手順）

特別なプログラミング知識は不要で、1分で導入できます。

### ステップ 1: Chrome に拡張機能を読み込む
1. Google Chrome を開きます。
2. アドレスバーに `chrome://extensions` と入力して Enter キーを押します。
3. 画面右上にある「**デベロッパーモード**」のトグルスイッチを **ON** にします。
4. 画面左上に表示される「**パッケージ化されていない拡張機能を読み込む**」ボタンをクリックします。
5. 配布された `applyonce-extension` フォルダを選択して読み込みます。
6. Chrome ツールバー右上のパズルピースアイコン（拡張機能一覧）から、「**ApplyOnce**」のピンを留めて常時表示にします。

### ステップ 2: 自分のプロフィールを登録する
1. ブラウザ右上の **ApplyOnce アイコン（青い A のマーク）** をクリックします。
2. ポップアップ右上の「**プロフィール設定 ↗**」をクリックします。
3. 基本情報（お名前、連絡先、学歴、エピソード等）を入力します。
   - *(AI生成機能を利用したい場合は、セクション04で OpenAI APIキー または Gemini APIキー を入力し、「接続テスト」を行ってください)*
4. ページ最下部の「**プロフィールを保存 →**」をクリックします。

### ステップ 3: 応募フォームで入力する
1. 企業の応募フォーム（エントリーページ）を開きます。
2. ツールバーの **ApplyOnce アイコン** をクリックします。
3. 用途に合わせてボタンをクリックします：
   - **「保存した情報を一括入力」**: ルールベースによる基本情報の即座入力
   - **「✦ 企業向けにAI調整して入力」**: ページの募集要項や設問構造を解析し、AIによる柔軟補完・文章作成を伴う入力
4. 入力された内容を目視確認し、規約同意やファイル添付を行った上で送信してください。

## フォルダ構成

- `manifest.json` — 拡張機能の定義ファイル
- `popup.html` / `popup.js` — クリック時に開く操作ウィンドウ
- `engine.js` — ページの構造解析および入力注入エンジン
- `options.html` / `options.js` — プロフィール設定・バックアップ画面
- `style.css` — デザインスタイルシート
- `icons/` — アプリアイコン画像
- `demo-form.html` — 動作確認ができるテスト用エントリーフォーム
