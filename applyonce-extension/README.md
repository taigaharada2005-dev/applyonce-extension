# ApplyOnce — 就活・転職エントリーフォーム一括入力アシスタント

就職活動や転職エントリーの面倒な入力作業（氏名、連絡先、住所、学歴、志望動機など）をワンクリックで一括入力できる Google Chrome 拡張機能（Manifest V3 対応）です。

DOM構造解析と最新AI（OpenAI `gpt-6-luna` / Google Gemini）を搭載し、企業ごとに異なる入力項目やドロップダウンの選択肢にも柔軟に適応します。

---

## 🔒 セキュリティと安心のプライバシー設計

- **ローカル保存**: プロフィールとAPIキーは`chrome.storage.local`に保存します。AI実行時はプロフィール・設問・補足情報を選択したAIプロバイダーへ、OCR実行時は画像をGoogle Cloud Visionへ送信します。各APIキーは認証先にのみ送信します。
- **機密情報の完全ガード**: パスワード、クレジットカード番号、認証コード（OTP）、規約同意チェックボックスなどは自動入力対象から自動的に除外されます。
- **自動送信なし（安全第一）**: フォームへの「下書き代行」のみを行い、**勝手な送信ボタンのクリックは行いません**。必ずユーザー本人が内容を確認してから提出してください。

## 🚀 導入手順（インストール方法）

パソコンの専門知識は一切不要です。**約1〜2分** でかんたんに導入できます。

### 【ステップ 0】準備：ファイルの解凍（※重要）

- **ZIPファイル（`applyonce-extension.zip`）を受け取った場合**:
  1. ダウンロードした ZIP ファイルを **右クリック ➔「すべて展開」**（またはダブルクリックで解凍）します。
  2. 解凍されたフォルダを開き、中に **`manifest.json` というファイルが入っているフォルダ（`applyonce-extension`）** があることを確認してください。
  > ⚠️ **注意**: ZIPファイルを解凍せずにそのままChromeに読み込ませることはできません。必ず解凍（展開）したフォルダを使用してください。

- **GitHubからダウンロードした場合**:
  1. GitHubリポジトリ画面の右上にある緑色の **「Code」** ボタンをクリック ➔ **「Download ZIP」** を選択します。
  2. ダウンロードされたZIPファイルを右クリックして **「すべて展開」** します。

---

### 【ステップ 1】Chrome に拡張機能を追加する

1. **Google Chrome** を起動します。
2. アドレスバー（URLを入力するバー）に以下を貼り付けて `Enter` を押します：
   ```text
   chrome://extensions
   ```
   *(または、Chrome右上のメニュー `︙` ➔「拡張機能」➔「拡張機能を管理」をクリック)*

3. 画面の右上にある **「デベロッパーモード」** のスイッチをクリックして **ON（青色）** にします。  
   *(※スイッチをONにすると、画面の左上に新しいボタンが表示されます)*

4. 画面の左上に現れた **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。

5. フォルダ選択画面が開くので、ステップ0で解凍した中にある **`applyonce-extension` フォルダ（`manifest.json` が直接入っているフォルダ）** を選択し、「フォルダーの選択」をクリックします。

6. 拡張機能一覧に **「ApplyOnce」** のカードが表示されれば読み込み完了です！🎉

---

### 【ステップ 2】アイコンを画面右上に固定（ピン留め）する（推奨）

応募フォームを開いたときにすぐ使えるよう、ブラウザのツールバーに固定します：

1. Chrome画面の右上にある **パズルピースのマーク（🧩 拡張機能メニュー）** をクリックします。
2. 一覧の中から「**ApplyOnce**」を探し、右側にある **ピンのマーク（📌）** をクリックします。
3. これで、Chrome右上にいつでも青い「**A**」アイコンが表示されるようになります。

---

### 【ステップ 3】初期設定：自分のプロフィールを登録する（初回のみ）

1. 画面右上の **ApplyOnce アイコン（青い A）** をクリックします。
2. ポップアップ画面の右上にある **「プロフィール設定 ↗」** をクリックします（新しいタブで設定画面が開きます）。
3. 各セクションにご自身の情報を登録します：
   - **基本情報**: 氏名（漢字・フリガナ・英字）、メールアドレス、電話番号、郵便番号、住所など
   - **学歴・専攻**: 学校名、学部、学科、文理区分、在籍状況、卒業予定年月など
   - **経験と文章の素材**: ガクチカ、自己PRの軸、研究内容、保有スキルなど（※AIで志望動機や自己PRを生成する際の「事実」として活用されます）

> 💡 **ヒント: APIキーがなくても使えます！**  
> 氏名・連絡先・住所・学歴などの基本情報の一括入力は、**APIキーなし・完全無料** で今すぐご利用いただけます。

4. **（おすすめ）AIによる設問回答・志望動機自動作成を使いたい場合**:
   - セクション04「AI連携」で、利用したいAIを選択します（**OpenAI 推奨**）。
   - OpenAIのAPIキー（`sk-...`）を入力し、**「接続テスト」** ボタンを押して「接続成功！」と表示されることを確認します。
   - モデルは初期設定の **`gpt-6-luna`**（高速・低コスト・フォーム解析に最適）のままでOKです。
5. ページ最下部の **「プロフィールを保存 →」** をクリックして設定を保存します。

---

## 📝 実際の応募フォームでの使い方

1. マイナビ、リクナビ、各社採用マイページ、Talentio、HERPなどのエントリーフォームを開きます。
2. 画面右上の **ApplyOnce アイコン（青い A）** をクリックします。
3. 2つのボタンから目的に応じて選択します：
   - **「保存した情報を一括入力」**:
     保存した基本情報（氏名・連絡先・住所・学歴など）を一瞬で自動入力します（APIキー不要）。
   - **「✦ 企業向けにAI調整して入力」**:
     ページ内の構造や募集要項をAIが解析し、基本情報の表記揺れ補完に加えて、設問（志望動機・ガクチカ・自己PRなど）の文章を字数制限に合わせて自動作成・入力します。
4. **【重要】目視確認と提出**:
   - 自動入力された内容を目視で確認します。
   - 履歴書PDF等のファイル添付や「利用規約に同意する」のチェックを手動で行い、送信ボタンを押してください。

## ❓ よくある質問・トラブルシューティング

### Q1. 「マニフェストファイルが見つかりません」または読み込みエラーになる
- **原因**: 選択したフォルダの階層が違っているか、ZIPファイルを解凍せずにそのまま選択している可能性があります。
- **解決策**: ZIPファイルを右クリックして「すべて展開」で解凍し、フォルダを開いたときに直下に **`manifest.json`** が見えるフォルダ（`applyonce-extension`）を選択してください。

### Q2. 登録した個人情報やAPIキーが外部に漏れる心配はありませんか？
- 保存先はブラウザ内です。AI・OCRを実行すると処理に必要な情報を各サービスへ送信します。OCR画像には表示中の個人情報が含まれる場合があるため、実行前に対象を確認してください。APIキーはJSONバックアップに含めません。

### Q3. APIキーは必ず登録しなければいけませんか？
- **必須ではありません。** 基本情報（名前、メアド、電話、住所、学歴など）の自動入力だけであれば、**APIキー登録なし・完全無料** でご利用いただけます。AIによる志望動機・ガクチカの自動執筆や選択肢の推論を利用したい場合のみ、OpenAIなどのAPIキーをご用意ください。

### Q4. 入力した文字が消えてしまったり反映されない欄がある
- React や Vue などの最新Webフォームでは、キーボード入力を検知しないと値が確定しない場合があります。ApplyOnceは自動で入力イベントを発火させていますが、もし反映されない項目がある場合は、その入力欄を一度クリックして末尾に1文字入力・削除してみてください。

### Q5. 別のパソコンに設定した内容を移したい
- 設定画面の一番下にある **「設定をJSON出力」** をクリックすると、設定ファイル（`applyonce-profile-backup.json`）がダウンロードされます。新しいパソコンで **「設定をJSON読込」** を選択すれば、一瞬で設定を復元できます（※セキュリティ保護のため、APIキーはバックアップファイルに含まれません）。

## 🧪 動作確認用デモページ

### Google Cloud Vision OCRで画像の情報を補足する

1. Google Cloud ConsoleでプロジェクトのCloud Vision APIと請求先を有効化し、APIキーを作成します。APIの制限はCloud Vision APIに設定してください。
2. プロフィール設定の「Google Cloud Vision OCR」で`OCR_API_KEY`を入力し、保存します。Chrome拡張は環境変数を直接読めないため、この設定欄を使用します。
3. 拡張機能を更新後、応募ページでポップアップの「画像の文字をOCRで補足」を開きます。「表示中のページをOCR」または「画像を選んでOCR」を実行します。
4. OCR結果を確認・編集してから「企業向けにAI調整して入力」を実行します。AI用APIキーも別途必要です。

表示中のページのOCR対象は画面内のみです。画像は9MB以下のPNG・JPEG・WebP・GIF・BMPに対応します。結果はポップアップを閉じると消えます。OCRは募集要項・設問の補足に使い、入力先の特定は既存のDOM解析で行います。画像だけの入力フォームやPDFの直接取り込みには対応していません。

公式の[文書OCRチュートリアル](https://docs.cloud.google.com/vision/docs/fulltext-annotations)と[OCRサンプル](https://docs.cloud.google.com/vision/docs/ocr)を参考に、`DOCUMENT_TEXT_DETECTION`と`fullTextAnnotation.text`を使用しています。日本語・英語が混在する画像も言語の自動検出に任せます。精度改善の程度は実画像で比較してください。

開発時の確認: リポジトリ直下で`node --test tests/ocr.test.cjs`を実行します。実APIの接続・認識精度は有効なキーと画像による別途検証が必要です。

正しく動作するかすぐに試せるテスト用フォーム（`demo-form.html`）を同梱しています。

1. Chromeで `chrome://extensions` を開き、ApplyOnce の「**詳細**」をクリックします。
2. 「**ファイルのURLへのアクセスを許可**」を **ON** にします。
3. `applyonce-extension/demo-form.html` を Chrome の画面上にドラッグ＆ドロップして開きます。
4. 右上の ApplyOnce アイコンから「保存した情報を一括入力」や「✦ 企業向けにAI調整して入力」を試すことができます。

## 📁 フォルダ構成

```text
applyonce-extension/
├── manifest.json      # 拡張機能の構成ファイル（Manifest V3）
├── engine.js          # DOM構造解析・フィールド判別・自動入力エンジン
├── popup.html / .js   # アイコンクリック時に開く操作画面
├── options.html / .js # プロフィール設定画面（API接続テスト・バックアップ対応）
├── style.css          # デザイン用スタイルシート
├── icons/             # 拡張機能用アイコン画像
├── demo-form.html     # 動作確認・テスト用の模擬応募フォーム
└── README.md          # 使い方・導入マニュアル
```
